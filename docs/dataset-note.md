# Evidence provenance

The substantive v3 evidence is generated by executing the same baseline workflow against the same stateful ARE tools used for replay. `challenge_data/learning/histories.json` contains ten synthetic histories: partial timestamped observations, actual actions, checks, feedback and outcome. `scripts/build_learning_demo.py` generates only the public debugging example; it is not a learning algorithm.

The public example world is transparent. Hidden worlds use different private policy predicates and future personas; only sanitized observations, histories and broker access go to the candidate. New corpora may contain unsupported feedback or no supported failures.

The old two-effect company fixtures and controller have been removed. The original three-world `core` pack remains a separate setup check and cannot satisfy v3 acceptance.

These are MIT-licensed synthetic challenge fixtures, not production data, a Gaia2 result or a live-model trace corpus. ARE is a separately licensed dependency. No benchmark download, provider credential or OAuth integration is needed.

The reference learner, learned workflows, private policies and raw grading runs are not distributed.
